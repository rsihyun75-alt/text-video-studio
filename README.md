# 컷메이커 — 텍스트 비디오 스튜디오

글을 입력하면 과제 안내의 5장면 구성에 맞춰 도입·발견·행동·전환·마무리 스토리보드를 만들고, 각 장면의 내레이션과 이미지 프롬프트를 정리하는 Next.js 풀스택 앱입니다.

## 주요 기능

- `/api/storyboard`에서 입력 글을 5개 장면 데이터로 변환
- 다큐멘터리·브이로그·모션그래픽 스타일 선택
- 장면별 미리보기, 타임라인, 자막/프롬프트 확인
- 스토리보드 JSON 다운로드 및 프롬프트 전체 복사
- 브라우저 `MediaRecorder`로 1280×720 WebM 영상 내보내기
- 입력 초안은 브라우저 localStorage에만 저장

## 실행

```bash
pnpm install
pnpm dev
```

## 배포

Vercel 프로젝트로 가져온 뒤 기본 Next.js 설정으로 배포할 수 있습니다. 외부 AI API 키 없이도 데모가 동작하도록 설계되어 있습니다.
